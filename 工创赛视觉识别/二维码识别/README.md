# 二维码识别显示

双击 `启动识别.cmd`，或在本文件夹运行 USB 摄像头预览（共用整合版的运行环境）：

```powershell
..\黑色圆环识别与数字识别\.venv\Scripts\python.exe -B qr_task.py --camera 1
```

仅识别和显示，不包含串口代码。按 Q / Esc 或关闭窗口退出。支持以 + 分隔的多组三位数字，例如 `123+321+456+654`，允许 0..9 并保留前导零，如 `012+009`。兼容此前的 `123321` 和 `1,2,3,3,2,1`。

识别状态和完整结果直接叠加在实时画面最上方，帧尺寸保持不变，窗口按原始画面尺寸显示。`QR decoded / VALID` 为识别成功，`Result` 保留各组数字及 + 分隔符；`No QR detected` 为没有二维码，`QR located / decoding...` 为已定位但未解码，`INVALID task format` 为已解码但格式错误。没有当前结果时显示 `Last valid`（历史成功结果），不代表当前帧仍在检测到二维码。

使用自己保存的现场二维码图片进行离线显示：

```powershell
..\黑色圆环识别与数字识别\.venv\Scripts\python.exe -B qr_task.py --image "你的二维码图片.png"
```

已通过生成二维码的解码、分组、前导零、非法格式拒绝和显示状态检查。实际摄像头解码效果取决于二维码清晰度、尺寸、光照和拍摄角度。

目录保留入口、启动文件、依赖清单和说明；缓存、日志及生成的测试图片已移至根目录 `清理备份`，不参与运行。
