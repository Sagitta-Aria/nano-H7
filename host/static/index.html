换算与安装方向

等待板端参数回读。保存与应用是两个操作。

位移 = 原始光流 / 10000 × 高度 × 比例，再进行轴向映射与安装角旋转。新参数只影响后续增量，历史累计不重算；修改后建议重新开始记录进行校准。地面坐标以首次有效 H723 航向为 +Y；缺失航向时暂停地面累计并报告缺口，H723 会话变化后锁定该坐标，需重启 H743 建立新坐标。传感器偏离转动中心时还需考虑旋转产生的位移。

连接后自动定位：S1（PH6）120°，S2（PH9）0°。舵机不受“使能输出”门控，也不会被“停止全部”切断—— 必须持续收到 50 Hz 脉冲才能保持位置。角度写整数即为整度（135 = 135.0°）， 只有出现小数点才表示小数；越界会被板端拒绝（ERR code=ANGLE_RANGE），不会静默截断。

P 越大，同样角差下轮速越高，受任务最高轮速及加速度限制；P 不设调参上限，支持非负数和两位小数，0 关闭纠偏。角度容差范围 0.01～10°，越小越严格，收敛可能更慢。输入后点击应用，运动时禁止修改；三个新采样稳定 300 ms 后完成，MCU 重启恢复默认。

M5 升降与 M6 旋转独立设置。先建立零位、保存参数并应用范围，再使能移动；两个常用位置均为绝对脉冲位置。

保存并应用后，以板端范围为准；修改范围要求该轴静止。确认升降方向及设置旋转零位须先解除使能。
