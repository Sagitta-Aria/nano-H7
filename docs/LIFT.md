# M5 升降轴 · v0.2.6

**v0.2.8 更新：** M5 升降与 M6 旋转已移至独立“升降与旋转”页，可设置脉冲范围、速度、单次步数和各自两个常用位置，见 [辅助轴操作](AUXILIARY.md)。下文 8000 为启动默认范围；新版允许显式应用自定义范围，`LIFT STAT` 的 max/min/剩余行程随板端实际配置变化。首次最高点初始化、方向确认、重连不重置的规则保留。

M5 使用 DIR=PC2、STEP=PH10。以最高点为零，向下的累计深度只能在 **0～8000 脉冲**内；上升最多回到零。8000 是相对最高点的总行程，不是每条命令的额度。超过剩余行程的整条命令会拒绝，不会自动截断。

v0.2.6 通过 `M5_DIR_INVERT=1` 反转 M5 的物理 DIR 电平。在相同 `LIFT DIR` 配置下，实际上下运动与 v0.2.5 对调；有符号位置及深度限位不变。不要再交换上位机的 UP/DOWN 命令，否则会破坏按钮与剩余行程的对应关系。需烧录本版 HEX 后生效；仅更新本地/Nano 网页不能改变旧固件的 8500 限位或电气方向。模拟板验证逻辑行程，不模拟物理 DIR 电平。

## 首次使用

1. 烧录 v0.2.6，重启上位机并刷新网页。每次 MCU 上电或复位后，先确保机构实际位于最高点，再连接上位机。
2. 上位机在 HELLO 握手后自动发送 `LIFT INIT`，将当前位置记为最高点零位，不产生脉冲。
3. 在“七轴运动调试”的 M5 卡片里，保持解除使能，选择已确认的方向：“正步数向下”或“负步数向下”，点击应用。默认方向未知，M5 不允许运动；不要在最高点随意试转来猜方向。
4. 使能后使用“向下”“向上”或“返回最高点”。页面显示当前位置和两个方向的剩余脉冲数。

**同一次 MCU 上电中只建立一次零点。** 重连、重复 INIT、HELLO 和 STOP 均保留原零点、累计位置及方向。若在下降后断连，重连不会把当前位置改成零。断电或复位会丢失位置和方向；下一次首次连接前必须恢复到实际最高点。

方向只允许在已初始化、M5 静止、解除使能且原始位置为零时配置。确认长期接线后，可以将 `firmware/include/app_config.h` 的 `M5_DOWN_SIGN_DEFAULT` 改成 1 或 -1 再编译；当前为 0，要求每次上电明确配置。

## 协议

以下是帧的正文，实际发送仍需序号和 CRC。HELLO 声明 `lift=1 lift_max=8000`。步数为正整数；速度 1～3000 step/s，加速度 1～20000 step/s²。

| 命令 | 作用 |
|---|---|
| `LIFT INIT` | 本次上电首次建立零点；重复调用只回读状态 |
| `LIFT STAT` | 回读升降状态 |
| `LIFT DIR 1` | 原始正步数表示向下 |
| `LIFT DIR -1` | 原始负步数表示向下 |
| `LIFT MOVE DOWN 100 300 1000` | 向下 100 脉冲 |
| `LIFT MOVE UP 100 300 1000` | 向上 100 脉冲 |
| `STOP` | 停止全部七轴并解除使能，保留零点和已发脉冲位置 |

运动需要 ARM 许可和持续心跳。INIT/DIR/STAT 成功后返回 `cmd=LIFT_STAT`；运动接受后返回 `cmd=MOVE axis=5 state=accepted move_id=...`，并不代表已经完成。

```text
OK cmd=LIFT_STAT axis=5 initialized=1 down_sign=-1 pos=100 max=8000 up_room=100 down_room=7900 active=0
```

`pos` 是向下为正的累计深度，`up_room` / `down_room` 是当前剩余行程；`active=0` 表示静止。原有 `AXIS 5` 的 `pos` 仍然是原始有符号步数：负步数向下时，两者符号相反。

原始 `MOVE 5 ...` 也经过同一固件限位检查。例如当前位置 5000，再向下 3000 可到 8000；请求 3001 则整条拒绝。返回最高点按钮读取当前 `up_room`，发送相同数量的 UP 脉冲。

| 错误码 | 原因 |
|---|---|
| `M5_NOT_REFERENCED` | 尚未 INIT |
| `M5_DIRECTION_UNKNOWN` | 尚未确认向下方向 |
| `M5_SOFT_LIMIT` | 目标深度小于 0 或大于 8000 |
| `M5_DIR_REQUIRES_TOP_DISARMED` | 不满足静止、零点、解除使能等方向配置条件 |
| `M5_BUSY` | 首次初始化时 M5 尚未停止 |
| `DISARMED_BUSY_OR_RANGE` | 运动未使能、轴忙或参数不满足要求 |

## 使用边界

这是根据已发 STEP 上升沿计数的**软件限位**，没有限位开关、编码器或自动寻零。失步、机械滑动、外力移动及复位后的位置不能被自动识别。向下符号必须与实际机构一致；配置反了，软件不能判断实际运动是否越过最高点。

STOP/心跳超时会停止后续脉冲，并完成已经开始的高脉冲；不提供机械抱闸或负载保持保证。底盘 HALT 只停止四个底盘轴。当前测试使用模拟通信和实际编译 ARM 代码，未烧录或驱动实物。
