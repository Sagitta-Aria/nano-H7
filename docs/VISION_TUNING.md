2026-10-19：已补齐 NX 部署。顶部新增独立“视觉调参”页，摄像头1页也有直达按钮。更新并重启用户服务后，9 份现场配置文件哈希全部保持一致；未使能或执行实车运动。

## 使用

打开 Web 上位机顶部“视觉调参”，可编辑六色 HSV、各色最小面积，以及圆环黑色亮度、面积、Canny、圆周支持比例、形状容差、检测宽度和近邻过滤距离。预览前在“摄像头1”选择 Nano 来源并打开设备；目标偏移、对准 PID、圆列间距仍在摄像头1页。

- **单帧预览**：用当前草稿处理相机新帧，返回识别图和分割图，不保存参数、不移动。
- **连续调参预览**：每次请求完成后等待 500 ms 再请求，最多一个请求在执行。可边改参数边观察；停止、切换页面、隐藏浏览器或失去控制权后不再继续请求。
- **保存视觉参数**：原子保存六色和圆环参数，下一次识别、对准及巡航视觉子任务使用保存值。NX 空闲显示重新读取保存值。控制台的预览类型/颜色不修改上方对准任务的类型/颜色。
- **读取保存值**：丢弃草稿并重新读取已保存配置。
- **载入新版原始参数**：载入此次提供的六份颜色 JSON 和圆环源码默认值；需要点击保存才持久化。

对准和自动任务运行期间拒绝修改或调参预览。预览通过现有相机进程取得原始帧，不另开相机，也不借用手动照片作为运动反馈。照片、调参结果、闭环识别使用独立消息和请求身份。

坐标和面积使用原始采集分辨率；网页图像最大显示宽度 960，不改变坐标含义。圆环调试图从左到右为全局黑色分割、局部黑色分割和 Canny 边缘。调参预览只检查几何检测，数字识别在 NX 显示和圆环任务中运行。

## 新版规则与参数

色块不限制圆形，用轮廓重心定位。黑色选最大有效色块，其余五色选最小有效色块；不再附加旧版圆度、完整入镜或 85% 实心覆盖限制。

| 颜色 | 导入最小面积 px² |
| --- | ---: |
| 红 | 3081 |
| 黄 | 2037 |
| 蓝 | 3133 |
| 绿 | 2037 |
| 黑 | 9034 |
| 浅蓝 | 1984 |

所有颜色仅使用 HSV 区间 1；界面、分割预览和实际识别一致。读取旧双区间配置时只保留第一组，保存后写入单区间；不会将两组范围合并或扩大区间 1。载入新版原始参数也只取第一组。红色第一段 H 为 12～12，纯 H=0 红色不在该段内；蓝色与绿色、浅蓝有交集，需结合现场曝光和分割图调整。

圆环同时使用边缘与孔洞分割路径，先合并同心观测，再按距离保留大环。默认原图圆心距离 ≤100 px 时过滤小环；控制台可调整距离，0 关闭此步骤。源码默认面积 50000 px²，检测宽度 960；缩放后自动换算面积与坐标。数字裁剪使用更新后的中心孔洞方法，排除同心线，识别完整单字 1/2/3。

## 保存与兼容

完整参数位于原 `camera_alignment.json` 新增的 `detector.colors` 与 `detector.ring`。六份源 JSON 是导入基准，Web 保存不会反写它们。

旧配置首次读取补全新字段，不立即改写磁盘，保留已有 PID、目标偏移、方向、圆列间距和旧的圆环面积/亮度。六色沿用旧版 HSV 的区间 1 和已保存的面积，不因升级改成新版默认值。存在 `detector` 后，以它作为检测参数来源；旧顶层 `min_area` / `black_max` 仅用于旧文件迁移。新安装使用完整新版默认值。需要采用新版原始值时，使用“载入新版原始参数”并保存。

生产源码位于 `工创赛视觉识别`，输入参考目录 `新建文件夹` 保持不变。替换前已有文件备份在 `localtmp/vision_before_console_20261017`。部署清单包含新模块、页面脚本、六色入口和六份 JSON，不复制 Windows `.venv`，不升级 NX 已验证依赖。

`RingOCR` 为运动控制返回当前帧的真实推理证据；`PreviewOCR` 的异步多目标投票只用于显示，缓存结果不会作为闭环的新采样。NX TensorRT 适配器兼容新的 ONNX Runtime 调用接口；兼容旧工具的 `nx_vision_fast` 已转发新版实现。已修正 Python 3.8 不支持的线程池关闭参数，并把 MJPG 设置放到分辨率等属性之后。
