# 摄像头1目标颜色与识别框调试

入口：`/debug` → 摄像头1 → **框内色块调试 · 不移动**。

先在上方选择色块和目标颜色；调参页选色与摄像头1目标保持同步。点击保存后，NX待机色块模式按保存目标检测，不会在红色缺失时改找黑色。屏幕分别显示 `Target`（目标）和 `Color`（实际找到的颜色），缺失显示 `--`。自动B点继续按任务码选择颜色。

调试框默认左上角15%、15%，宽高70%。可修改四个整数百分比，或读取已保存的B点识别框。点击单帧或连续预览，真实相机帧仅在框内检测，结果图显示青色框，二值图显示框内分割。页面同时显示检测端返回的目标、原图坐标、HSV上下限和最小面积。调试框不写入B点参数，不参与车辆对准；停止预览、切换页签或隐藏页面会取消连续预览。HSV草稿预览无需保存，待机屏幕和后续任务使用保存值。

2026-10-19现场核验：API参数与NX保存文件一致。保存红色H范围为12～12、S80～255、V46～255、面积3000；实拍红色物块中心区域色相主要为175～178。相同实拍图使用原范围无结果，内存试验改为H170～179后找到中心(346,288)，未写入该HSV修改。已将目标从black选为red，其他参数保留。不同光照和物块仍需实际调试。
