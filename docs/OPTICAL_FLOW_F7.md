## 接线和安装

模块供电为 3.7～5.5 V，规格书标称 5 V 时电流 175 mA；UART 信号为 3.3 V LVTTL。
供电电压和通信电平是两件事。接口从 Pin1 到 Pin4 为 5V、RX、TX、GND。
模块 TX 接接收端 RX，模块 RX 接发送端 TX，两边共地。

UART 参数为 115200、8N1，无流控，初始化时间在 3 秒内。支持 200 Hz 或 400 Hz 输出；规格书没有提供切换命令。

这是微距型号。规格书的空气中有效工作距离为：

| 表面条件 | 距离 |
|---|---|
| 弱纹理 | 2～3.5 cm |
| 纹理丰富 | 1.5～5.5 cm |

水下距离另为弱纹理 3.5～5 cm、纹理丰富 3～6 cm，不能套用到空气中的测试。
首次桌面测试建议镜头朝向有纹理的平面，保持约 3 cm 距离和平行姿态，先静止，再沿两个方向平移。
这个建议是依据工作距离选取的测试起点，最终安装高度和位移比例仍应实测标定。
模块镜头面有 X/Y 方向丝印，坐标方向参见规格书图 4；不要直接假定它与车体方向一致。

## 14 字节 Upix 报文

下表使用从 1 开始的字节编号，多字节字段低字节在前。

| 字节 | 字段 | 含义 |
|---|---|---|
| 1～2 | `FE 0A` | 固定包头，0A 表示后面的数据结构体有 10 字节 |
| 3～4 | `flow_x_integral` | X 方向本次周期的角位移积分，放大 10000 倍 |
| 5～6 | `flow_y_integral` | Y 方向本次周期的角位移积分，放大 10000 倍 |
| 7～8 | `integration_timespan` | 本次积分周期，单位 µs |
| 9～10 | `ground_distance` | 预留，忽略；不能作为实测高度 |
| 11 | `valid` | 0 无效，255 最可靠，中间值越大置信度越高 |
| 12 | `version` | 版本号，规格书要求忽略 |
| 13 | XOR | 第 3～12 字节共 10 字节的异或 |
| 14 | `55` | 固定包尾 |

X/Y 在实际解析中按小端有符号 16 位数处理，以保留负方向。规格书没有明确写出 C 类型，这一处理也与采集到的负数二补码相符。
串口每次读取可能只拿到半帧，或者一次拿到多帧；需要缓存、寻找包头、核对包尾和 XOR，遇到损坏数据后重新同步。
通过帧校验和 `valid` 非零是不同检查，均应处理；规格书没有规定可用于控制的最低置信度阈值。

## 位移和速度换算

令已知或实测的镜头至平面距离为 `h_mm`，本次报文 X/Y 原始值为 `fx`、`fy`，周期为 `dt_us`：

```text
dx_mm = fx / 10000.0 * h_mm
dy_mm = fy / 10000.0 * h_mm
vx_mm_s = dx_mm * 1000000.0 / dt_us
vy_mm_s = dy_mm * 1000000.0 / dt_us
```

例如 `fx=69`、高度 30 mm、周期 5065 µs，对应本周期位移 0.207 mm，平均速度约 40.9 mm/s。
这是换算示例，并非本次实测安装高度或位移。

规格书 §5.3 把 `0x13C9` 写成 5056 µs，存在十进制笔误；正确值是 5065 µs。
同节的“69 rad”应结合后面的放大 10000 倍说明理解，实际角位移是 0.0069 rad。

固定安装高度时可以累计各帧增量估计相对运动；高度变化会影响比例。
用于机器人全局坐标时，还需要校准模块与车体的轴向关系，并结合航向把车体增量旋转到全局坐标。
v0.2.11 已加入独立光流驱动与位移显示。巡航控制仍使用原来的脉冲里程计；光流当前用于测量和校准，没有接入电机控制闭环。

## 本次实物采集

电脑经 CH340 USB 转 TTL 接收，最终识别为 COM38、115200 8N1。
约 5 秒原始记录中识别出 920 个包头、包尾、XOR 全部正确的帧，另外有 59 个不合格包头候选。
不合格候选数量不是严格的丢帧率统计，数据损坏也可能破坏包头。

- X 原始值范围：-36～36；Y：-22～36。
- 积分周期：5065～5066 µs，对应约 197.4 Hz，符合标称 200 Hz 档位。
- `valid`：94～120，没有 0；尚未验证高置信度场景或实际位移精度。
- `version`：1。

实测证明接收链路能够读到该协议的数据，不证明定位精度、比例标定、轴向或长时间稳定性。

## H743 接线与上位机操作（v0.2.11）

| 模块 | H743 |
|---|---|
| TX（3.3V UART） | PB11 / USART3_RX / AF7 |
| RX（可选，当前不下发模块命令） | PB14 / USART3_TX / AF7 |
| 5V | 5V 电源，需满足模块电流 |
| GND | GND，共地 |

USART3 为 115200 8N1。接到 H743 后，上位机连接 H743 原有串口或 Nano 链路，在“光流位移”页查看；无需使能电机。

- **上电累计**：从 H743 初始化接收后逐帧累加，断开或重新打开上位机不会清零，H743 重启归零。
- **从现在开始记录**：以板端处理命令的 MCU 毫秒时刻建立基线，同时记录两种坐标的增量。再次开始建立新基线，不影响上电累计。
- **结束并保留记录**：冻结该段记录与结束时刻，上电累计继续增长。
- X、Y 为有符号分量；合成长度为 `sqrt(X²+Y²)`，是净位移。往返抵消，不累计路程。
- 两种坐标在板端同时累计，界面切换只选择显示结果。当前只保留最近一段记录，不提供任意历史时刻回溯或记录文件导出。

固定轴向使用安装校准后的轴，每帧直接相加。小车转向时，这些轴跟着车转，因此该模式适合桌面校准及不转弯测量。

航向模式通过现有上位机 H723 桥接接收 `NAV IMU`，以首次有效航向定义地面 +Y、右侧为 +X，顺时针航向为正；每帧先转到地面坐标再相加：

```text
θ = 当前航向 - 首次有效航向
world_dx = cos(θ) * dx + sin(θ) * dy
world_dy = -sin(θ) * dx + cos(θ) * dy
```

首次有效航向之前、航向无效或超过 300 ms 未更新时，固定轴向继续累计，地面坐标跳过对应帧并统计缺口。上位机断开期间 H743 仍收光流，但现有 H723 航向桥接会停止，因此地面累计可能不完整。H723/桥接会话编号变化时，地面累计保持旧值并锁定，须重启 H743 建立新的坐标，避免混合不同航向零点。上位机连接重建也可能改变桥接会话编号。界面显示缺口和锁定状态。

## 安装后的校准

1. 量镜头到测量平面的实际距离，填写高度；默认 **30 mm 只是待校准值**。确认处于上述微距工作范围，地面纹理稳定，置信度不为零。
2. 选固定轴向模式，沿希望的 +X/+Y 各移动一段已知距离。用“交换 X/Y”“反转 X”“反转 Y”调整轴向；安装角顺时针为正，任意角旋转作用于映射后的增量。
3. 在相同高度下开始新记录并移动已知距离，比例按 `新比例 = 旧比例 × 实际距离 / 显示距离` 调整。X/Y 分别标定，避免把来回路程与净位移比较。
4. 点击“保存参数”仅保存到主机 `host/optical_flow.json`；点击“应用已保存参数”才发送到 H743。板端回读显示当前实际参数。主机重连不会自动覆盖板端参数。
5. 参数只改变后续帧，历史累计和已结束记录保持原值。修改后重新开始记录再标定。H743 参数保存在 RAM，断电恢复默认，需要重新应用主机保存值。
6. 安装后可切换航向模式观察转弯运动。模块偏离车体转动中心时，旋转自身会产生平移；当前没有传感器杆臂补偿。高度变化、纹理、振动和光流漂移仍会影响精度。

处理顺序为：交换原始轴 → 各轴比例与符号 → 顺时针安装旋转 → 固定轴累加 / 按航向旋转后累加。内部以整数纳米累计，上传四舍五入的整数微米，上位机换算为 mm 显示三位小数；显示精度不代表传感器精度。

## H743 主机协议

沿用已有 ASCII 序号与 CRC 封装，每条 `FLOW` 命令均在通信任务执行，不要求 `ARM`。

| 命令 | 行为 |
|---|---|
| `FLOW STAT` | `FLOW_STAT`：固定轴总量 `x_um/y_um`、记录量 `rx_um/ry_um`、记录/接收状态与计数 |
| `FLOW WORLD` | `FLOW_WORLD`：地面总量 `wx_um/wy_um`、记录量 `wrx_um/wry_um`、航向/锁定/缺口 |
| `FLOW CONFIG` | `FLOW_CONFIG`：板端当前校准参数及 `rev` |
| `FLOW START` | 建立记录基线，返回 `FLOW_STAT` |
| `FLOW STOP` | 冻结记录，返回 `FLOW_STAT`，重复停止保持同一结果 |
| `FLOW CONFIG h gx gy map angle q` | 原子验证并更新校准，返回 `FLOW_CONFIG` |

配置整数单位与范围：`h` 为 µm（1000～1000000）；`gx/gy` 为 ppm（10000～10000000，即比例 0.01～10）；`map` 为 0～7 位掩码（bit0 反转 X，bit1 反转 Y，bit2 交换）；`angle` 为百分之一度（−18000～18000）；`q` 为最低置信度（1～255）。例如默认值：

```text
FLOW CONFIG 30000 1000000 1000000 0 0 1
```

`marked=1` 表示已有记录，`recording=1` 表示仍在记录。`start_ms/end_ms/now_ms` 为 MCU 32 位毫秒计数，约 49.7 天回绕；时段差按无符号差计算。`online=1` 表示 200 ms 内收到校验正确的帧，与采用阈值是两件事。`valid` 是最新置信度，`dt_us` 是积分周期，`fx/fy` 是原始有符号增量。

`frames` 是校验正确的帧数，`accepted` 是采用帧数，`bad` 包含损坏候选、零周期和半帧超时，`low` 是低于置信阈值的帧数，`uart` 是 UART 或接收环溢出次数。`heading` 表示当前地面航向可用，`locked` 表示坐标已锁定，`gaps/rgaps` 分别是上电/记录的航向缺失采用帧数，`world_ms` 为地面坐标建立时刻。`sat=1` 表示累计超范围暂停。

USART3 中断只写入 1024 字节接收环；通信任务每次至多处理 512 字节，并在逐条处理主机请求前再次排空，避免一批长串口回复饿死光流接收。损坏帧重新同步；接收环溢出时丢弃积压和半帧，统计错误；不把二进制光流数据送入电机命令解析器。

## 软件验证与边界

ARM Compiler 5 / MicroLIB 编译实际 H743 固件，再用 Unicorn 执行 AXF 中的串口中断、解析、换算、记录与协议函数；覆盖正负往返、半帧/坏 XOR、真实 920 帧回放、纳米增量长期累计、映射旋转、航向缺失/会话变化、环溢出恢复和时钟回绕。Web 使用 Edge/Playwright 验证保存/应用、停止冻结、页面重开、草稿保留及手机布局；Tk 使用 SIM 验证控件及传输。

这些检查不验证物理 UART 时序、安装方向或毫米精度。本次没有烧录新版固件，没有驱动实际电机。安装后需要应用实测高度，并用已知距离分别标定 X/Y。
