# M5 升降与 M6 旋转 · v0.2.15

Web 与 Tk 增加独立“升降与旋转”页。每轴可设置脉冲下限/上限、速度、加速度、单次移动大小，以及两个绝对常用位置。常用位置可手输，或在轴静止时“记录当前位置”，然后保存。设置保存在上位机 `host/auxiliary.json`；Web/Tk 保存当前轴；连接时必须收到板端新范围确认后才保存。普通状态轮询不会覆盖正在编辑的设置。

M5 使用向下为正的深度，最高点为零，默认范围 0～8000；M6 使用原始有符号脉冲位置，正反转不预设顺逆时针，不换算角度。M6 默认保存范围 0～0，需按实际机构填写允许旋转行程。范围是累计位置限制，单次步数是相对当前位置的移动量。

## 操作

1. 烧录新版 HEX，握手应显示 `fw=0.2.15 aux_control=1 aux_live=1`，更新上位机并刷新页面。旧固件不能使用新的专用范围和位置接口。
2. M5 每次 MCU 上电后的首次连接前仍需处于实际最高点；握手自动 `LIFT INIT`，同次上电重连不重置。解除使能，在最高点明确选择 M5 的向下符号。
3. M6 将机构放在选定参考位置，解除使能且该轴静止，点击“当前位置设为零”。只改变脉冲参考，不产生运动，不是自动寻零；重连不会自动执行。
4. 填入本轴允许范围、速度、单次步数和两个常用位置，点击“保存并应用”。连接时发送 AUX CONFIG，收到匹配的新范围后才保存；失败保留原保存参数。离线保存仅写配置，连接后仍需应用。
5. 应用要求该轴静止、参考已建立，新范围必须包含当前位置。0.2.15 固件允许已使能但静止时修改；旧固件仍须解除使能。界面以板端实际范围确认生效，草稿范围不同会阻止专用页运动。修改范围不移动、不重设零位；另一轴的草稿保留。
6. 使能后，“向上/向下一步”“正转/反转一步”按设定单次大小执行；常用位置“前往”由板端从实际脉冲计数计算差值。重复点击、忙轴、越界整条拒绝，不静默裁剪。
7. “停止 M5/M6”只停止该轴，完成已经开始的高脉冲，不新增上升沿，保留其他轴和 ARM；停止全部仍停止七轴并解除使能。

速度 1～3000 step/s，加速度 1～20000 step/s²。M5 可配置 0～1000000 内的非零宽度范围；默认 8000 不再是不可更改的编译上限。M6 范围端点在 ±1000000 内，可设负数；两个常用位置必须在保存范围内。扩展范围前需按实际机构确认端点，程序不能测量物理行程。若 M5 下限大于 0，返回最高点按钮不可用，旧 UP 指令也不得低于下限。

## 板端接口

以下是帧正文，仍需协议 v1 序号与 CRC。axis 为 5 或 6。

| 命令 | 行为 |
|---|---|
| `AUX STAT <axis>` | 回读逻辑脉冲位置、范围、参考/配置标记、运动状态 |
| `AUX ZERO 6` | M6 当前位置设为零；静止且解除使能，已配置范围须包含 0 |
| `AUX CONFIG <axis> <min> <max>` | 应用本次 MCU 上电内的范围；不运动、不重置位置 |
| `AUX STEP <axis> <delta> <sps> <accel>` | 相对逻辑脉冲位移；M5 正 delta 向下 |
| `AUX GOTO <axis> <position> <sps> <accel>` | 跳转绝对逻辑脉冲位置；已在目标位置时成功但不发脉冲 |
| `AUX HALT <axis>` | 单轴停止，保留位置、范围和 ARM |

`AUX STAT` 示例：

```text
OK cmd=AUX_STAT axis=6 pos=-100 min=-4000 max=4000 referenced=1 configured=1 active=0
```

GOTO/STEP 成功返回 `cmd=AUX_MOVE state=accepted`，只表示接受；需 `active=0` 与目标 `pos` 判断脉冲完成。位移计算、范围检查和启动在同一临界区；原始 `MOVE 5`、`LIFT MOVE` 也遵守 M5 新范围，M6 应用 CONFIG 后原始 `MOVE 6` 同样受限。七轴页仍是底层调试入口：首次配置前的原始 M6 MOVE 保留旧行为，日常机构操作应使用专用页。

错误：`AUX_ZERO_REQUIRES_M6_DISARMED_IDLE`、`AUX_CONFIG_RANGE_REFERENCE_OR_BUSY`、`AUX_NOT_READY_BUSY_OR_LIMIT`。旧 M5 命令仍使用原错误码。`LIFT STAT` 新增 min，max/up_room/down_room 随实际配置变化；HELLO 的 lift_max 8000 表示启动默认范围。

## 保存和参考的边界

保存的参数与两个常用位置在上位机重启后保留；板端参考、当前位置、配置范围在同次 MCU 上电的断线重连后保留，断电/复位后丢失。重启后 M5 恢复默认范围，M6 专用运动等待零位和范围设置。已保存的常用位置只有在重新建立相同物理零位后才有原来的含义。

位置是 STEP 计数，没有物理限位、编码器反馈或掉电位置恢复。停止没有新增机械抱闸保证。参数保存在运行上位机的主机上，PC 与 Nano 各有自己的文件；本次本地修改不会自动同步 Nano 的保存参数。
