# NX 实拍数字 1 回归样本

这些 640×480 原始帧由用户现场测试的 USB 摄像头采集。预期目标是最小完整黑环内的数字 **1**；右侧可能出现被画面截断的数字 2。

- `1792051945478247274_frame.png`、`1792051946402762714_frame.png`：原算法实测无数字输出，外圈与灰色纸面干扰裁剪。
- `179205263*_frame.png` 三张：第二组现场不稳样本，补充验证数字 1 的留白与细笔画处理。
- `179205354*_frame.png` 八张：后续纸张倾斜姿态下的新样本，用于检查窄字的剪切校正和 OCR 输入处理。

用 `tools/validate_nx_vision_live.py` 在 NX 的 `vision-env` 中回放，具体命令见 `docs/VISION_ENV.md`。样本验证已知问题，不代表完整现场测试集。
