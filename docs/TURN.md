# 独立陀螺仪闭环转角（0.2.16）

Web 和 Tk 上位机的“底盘运动”页增加“陀螺仪闭环转角”。转角由 H743
执行，继续使用 TIM8 STEP/DIR；H723 航向仍经上位机约 20 Hz 转发。
不需要建立 O 点、配置路径或启动巡航。转角零点与巡航坐标/出发朝向分别保存。

## 使用

连接 H743（握手 `fw=0.2.16 turn=1 turn_tuning=1 turn_precision=1`）和 H723，等待陀螺仪校准及有效航向。
真实板沿用原有接线确认、使能输出流程。输入角度、最高轮速及加速度后执行：

- **相对当前方向转动**：H743 接受命令时的车头方向为本次 0°。
  `90` 为顺时针转 90°，`-90` 为逆时针转 90°，不需要设置零点。
- **转到零点角度**：在底盘静止且航向有效时点击“当前方向设为零点”，
  然后转到相对该零点的指定角度。例如先到 90°，再输入 0°可回到零点。

角度范围 −180～180°，最多两位小数；按最短角差执行，恰好 180°时固定顺时针。
输入速度是每轮脉冲/秒，也是转角最高轮速；不再另设隐藏的 600 step/s 上限。
P 默认 20 (step/s)/°，不设调参上限，支持非负数和两位小数，0关闭纠偏；角度容差默认 ±0.2°、范围 0.01～10°。

0.2.18取消原P200上限，上位机和板端均接受500、1000等值，不静默截断。
协议以P×100存入有符号32位整数，因此仅保留表示容量边界2147483647
（P最大可表示21474836.47），拒绝负数、NaN/Infinity和无法精确表示的第三位小数。
P=0不产生航向修正，也不再触发最小1 step/s输出；转角/巡航调姿在角差未满足时
不会报告完成，IMU新鲜度及转向超时仍有效。直线平移继续执行但没有P纠偏。
较大P的轮速计算先以64位乘法计算再饱和到任务最高轮速，避免32位溢出使输出变慢。
此行为需要0.2.18固件；旧固件即使上位机允许输入，仍会拒绝超出旧范围的命令。
Web 在陀螺仪、底盘运动、坐标巡航三页提供同一组参数，Tk 在闭环转角区域提供两项输入。
输入后点击“应用陀螺仪参数”，
以状态中的板端 P 确认生效。P 和角度容差同时作用于独立转角和巡航调姿，MCU 重启恢复默认。
轮速为 |角差|×P，最低 1 step/s，最高为任务设置的最高轮速；底盘运动期间禁止修改 P。
接近目标时按角差降低速度，误差不超过配置的角度容差、全部 STEP 输出停止后，
至少三个新航向采样持续确认 300 ms 才报告完成。完成后不持续保持角度。

“停止转角”只结束独立转角，保留输出使能及 M5～M7。
底盘 HALT、巡航 STOP、全轴 STOP、解除使能也取消独立转角。
点动、原始四轮命令、坐标巡航与转角互斥；辅助轴可以独立运行。
指定转角不会因为切换页面而取消，使用停止按钮结束。

航向超过 300 ms 未更新、数据失效、H723 会话改变或转向超过 60 秒均停止。
恢复反馈不会自动继续。转角零点仅存在 H743 RAM；H743 复位、H723 重连/重启
使旧零点失效，绝对模式要求重新设零，相对模式可以在反馈恢复后重新执行。
心跳仍每 250 ms 发送，1 秒通信超时由原有监督任务停止全部七轴。

## 协议

仍使用原 v1 序号及 CRC 帧，以下为正文；角度单位为百分之一度：

```text
TURN CONFIG 8000 50
TURN ZERO
TURN MOVE REL 9000 500 2000
TURN MOVE ABS -9025 500 2000
TURN STAT
TURN STOP
```

`TURN CONFIG <P×100> <容差×100>` 同时应用两项参数，例 `8000 50` 为 P80、容差±0.5°。仅静止时接受，返回实际 `kp_centi` 和 `tolerance_cd`。旧的单参数 CONFIG 仍可调 P，并保留当前容差。错误或忙时两项均不改变。

`MOVE` 后依次为模式、角度、最高 step/s、加速度 step/s²。
`TURN_MOVE state=accepted move_id=...` 只表示任务接受；轮询 `TURN STAT`
并匹配编号，`state=done` 才表示闭环稳定确认完成。同序号重放不会重捕获起始角度。

状态字段：`state=idle/turning/done/stopped/fault`、`mode=REL/ABS`、
`zero=0/1`、`current_cd`、`target_cd`、`error_cd`、`imu=0/1`、
`move_id`、`active`、`fault`。当前/目标/误差均以最近一次任务的基准表示；
REL 的基准是接受时航向，ABS 的基准是设定零点。`imu=0` 时角度仅为缓存值。

Web 接口 `/api/turn/action` 沿用控制页令牌限制。请求包含
`action=zero/start/stop/configure`；configure 带 `kp`、`tolerance`（度）；省略 tolerance 兼容旧的仅 P 接口；start 可带 `mode`、UI 度数 `angle`、`sps`、`accel`。

## 响应速度与参数

0.2.17 的[辅助直线](STRAIGHT.md)与坐标巡航直线段复用本页 P/容差。P 控制差速分量，容差作为行驶纠偏死区；转角任务的完成与稳定采样判据保持有效。

相同角差下，P20在1°误差处要求20 step/s，P80要求80 step/s；最高轮速和加速度仍限制实际响应。P增大可能增加过冲，容差放宽可减少最后细调。网页输入仅保存在浏览器草稿中，点击应用并确认板端反馈才生效，运动时禁止修改。容差与传感器自身精度不同。

2026-10-14 只读检查时，实车已由用户更新为0.2.15，但Nano仍为14:35:14启动的旧后台、板端P20。新功能需要0.2.16固件及后台重启；继续遵守用户等待调试结束再重启的要求。
